# MURAD SOLO CHALLENGE

ئەپێکی تاقیکردنەوەی تایبەتی بە زمانی کوردی (سۆرانی)، ١٥ پرسیاری قورس، ٦ چرکە بۆ هەر پرسیار، مۆزیکی پشتەوەی دروستکراو بە Web Audio و هەژمارکردنی کۆی کات.

## بڵاوکردنەوە لە Render (خۆڕایی)

1. ئەم ZIP ـە بکەرەوە و ناوەڕۆکەکەی بخەرە ناو GitHub repository ـێکی نوێ.
2. بچۆ بۆ https://render.com و بە GitHub بچۆ ژوورەوە.
3. لە Render، `New` → `Blueprint` هەڵبژێرە و repository ـەکەت دیاری بکە.
4. Render فایلەکەی `render.yaml` دەخوێنێتەوە؛ `Apply` بکە.
5. چاوەڕێ بکە تا Deploy تەواو دەبێت؛ پاشان لینکی `.onrender.com` بکەرەوە.

## تێبینی
- ئەپەکە بۆ مۆبایل و لاپتۆپ گونجاوە.
- هەر پرسیارێک ٦ چرکەیە؛ بە تەواوبوونی کات، وەڵامەکە بە هەڵە تۆمار دەکرێت.
- کۆی کات لە دەستپێکردن تا تەواوبوونی پرسیاری ١٥ هەژمار دەکرێت.
- وەڵامی ڕاست لە API ـی Python دەپارێزرێت، نەک لە JavaScript.
- مۆزیک و دەنگەکان بە Web Audio دروست دەکرێن؛ پێویست بە فایل یان مۆڵەتی مۆزیکی دەرەکی نییە.
- پلانی خۆڕایی Render لەوانەیە دوای ماوەیەک خەو لێ بکەوێت و یەکەم کردنەوەی دوای خەو کەمێک خاو بێت.
